# BidPoint project discovery

Status: Canonical
Last validated: 2026-08-01

This area gathers the discovery material that defines BidPoint's intended product and technical direction before delivery work starts.

**New developer or AI session:** begin with the [standalone handoff](design-system/2.0/99-handoff.md), then use the [2.0 index](design-system/2.0/README.md).

`design-system/` holds versioned design baselines:

| Baseline | Status | Contents |
| --- | --- | --- |
| [2.0](design-system/2.0/README.md) | **Canonical** | Current baseline. Six documents revising technology periphery, pin policy, and delivery sequence. Inherits 1.0's domain, ownership, and messaging documents unchanged. |
| [1.0](design-system/1.0/README.md) | Superseded | Original discovery corpus, 24 documents. Kept intact as history and rationale. |

Where the two conflict, 2.0 wins. The [decision delta](design-system/2.0/04-decision-delta.md) records every change and why.

Discovery describes the target design; it does not describe an existing implementation. No application code or infrastructure exists yet.

> The [structure template](structure-template/) is a brainstorm of what a layout could look like, not a target the implementation is expected to match. Every file in it is empty, and parts of it are outdated. It is not an initialized workspace.
